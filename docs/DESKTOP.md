# 一体化心电分析程序

双击 WeiBuXinZhi.exe，稍等启动窗口显示服务就绪，浏览器会自动打开。
首次使用先注册本地账号，再登录。导入原始 ADS1292R CSV 或 raw_mV.csv，默认采样率 500 Hz。
原始 CSV 自动使用参考电压 2.42 V、PGA 6 换算；已转换 mV 文件不会再次换算。
包含离线节律显示滤波代码，模型输入仍为未滤波 mV，由模型自身处理；详情页当前显示原始波形。
OpenECG 当前分析前 10 秒，需至少 10 秒、500 Hz 单导联信号。结果仅用于研究。
无需安装 Python、Node 或联网调用 AI。界面使用本机默认浏览器。
关闭启动窗口停止服务；只关闭浏览器不会停止服务。

数据默认保存到 %LOCALAPPDATA%\WeiBuXinZhi，日志为 desktop.log。
这是独立数据目录，旧网页版的账号和历史记录不会自动迁移；旧项目及 Records 文件原样保留。
备份时先关闭启动窗口，再复制整个数据目录。EXE 可替换，数据目录应保留。

当前覆盖 CSV → 电压换算 → 波形 → AI → 历史记录/导出。
尚未包含 COM3/JDY18 实时采集控制，也没有自动识别硬件采样率。
程序首次启动需解压内置科学计算库和模型，可能需要几十秒。

开发者重建：安装 requirements-ai.txt、pyinstaller，前端 npm ci，然后运行 build_desktop.ps1。
验证：1440px / 390px 浏览器检查、CSV 默认 500 Hz、真实公开样本上传分析，以及冻结 EXE 自检。
