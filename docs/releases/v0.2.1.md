## 用户可见变化

打开一条心电记录，先看到估算心率、检测心拍及信号质量，再查看实际波形与心拍类别。未分类心拍单独展示，避免总数与分类数不一致。逐拍概率、质量原因、记录来源和技术参数仍可展开核对。原始与滤波波形来自同一条记录的真实样本，不使用演示图替代。

图片导出仍在页面上方；其他操作收进“更多操作”。共享记录沿用已有权限，备注、重分析来源和删除确认仍保留。手机视口采用紧凑指标与双列心拍分类布局。

完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## 更新方法

使用 PowerShell 7，在自己的项目目录中先检查 `git status`。有本地改动时先提交或备份，避免与组员正在做的内容混在一起。

跟随集成分支：

```powershell
git fetch origin --tags
git switch ai
git pull --ff-only origin ai
Set-Location frontend
npm.cmd ci
npm.cmd run build
Set-Location ..
```

若本地尚无 `ai` 分支，使用 `git switch --track origin/ai` 创建跟踪分支。需要精确复现本次版本时，改用 `git switch -c local/v0.2.1 v0.2.1`，不要将已经前进的 `ai` 分支强制重置。

本次仅前端代码和测试断言变化，没有数据库迁移、依赖升级或模型权重更新。构建完成后，使用原来的 Python 环境和启动方式启动应用，刷新浏览器。`run_pc.py` / 桌面启动器读取 `frontend/dist`；已经打包的旧 EXE 需重新打包才包含新版。
