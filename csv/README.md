# 公开 ECG 联调样本

本目录存放测试数据；自动测试脚本统一位于仓库根目录的 tests/。
个人心电、上传记录、账号和运行数据库不应提交到 Git。

## 可上传样本

- 文件：ptbxl_00001_lead_II_500Hz_10s.csv。
- 来源：PhysioNet PTB-XL v1.0.3，原记录 records500/00000/00001_hr。
- 官方页面：https://physionet.org/content/ptb-xl/1.0.3/
- 采样率 **500 Hz**，样本数 **5000**，时长 **10 秒**。
- 从原始 12 导联记录中提取 **II 导联**，单位 **mV**，单列 mv 表头。
- 转换：WFDB format 16、小端有符号整数；mV = (ADC - 0) / 1000。
- 无重采样、拼接、重复或补点。转换记录与 SHA-256 见来源 JSON。
- 原数据作者：PTB-XL 数据集作者，具体署名和引用信息以官方页面为准。
- 原数据许可：CC BY 4.0，完整许可见 LICENSE-PTBXL.txt。
- 本文件是原始数据的单导联 CSV 转换版本，仅用于软件联调，不属于当前网站账号的个人心电。

在“导入与分析”页面选择该 CSV，采样率填写 **500**。
单条样本成功仅说明分析链路可运行，不代表模型临床性能已验证。

原始下载缓存和临时任务编号由 Git 忽略；测试代码请保留在 tests/。
