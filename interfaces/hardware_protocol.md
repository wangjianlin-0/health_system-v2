# 硬件通信协议

## 版本与状态

2026-10-21，依据[根 README](../README.md)。硬件模块负责真实设备，当前仅合成回放可用，协议未确认。

## 概述

设备方案与实际接口需核实；下列帧和命令仅保留为候选草案，不代表设备已支持。

## 参数

| 参数 | 当前约定 |
|---|---|
| 采样率 | 以实际 sample_rate_hz 为准；软件接受 50–2000 Hz，不固定 500 Hz |
| 分辨率 | 待核实，不默认 12 bit |
| 单位 | 标准输入 mV，ADC 换算须标定 |
| 传输/字节序 | 待确认，不默认 USB、无线或小端二进制 |
| 导联 | 首版单导联，12 导联为扩展 |

## 帧格式

候选 SOF | LEN | CMD | PAYLOAD | CRC；长度、序号、时间、缺失标记及校验算法待定，无收发实现。

## 命令码

| CMD（草案） | 名称 | 方向 |
|---|---|---|
| 0x01 | DATA_FRAME | 设备→后台 |
| 0x02 | HEARTBEAT | 设备→后台 |
| 0x10 | START | 后台→设备 |
| 0x11 | STOP | 后台→设备 |
