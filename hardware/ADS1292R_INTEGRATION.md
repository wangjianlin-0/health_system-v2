# ADS1292R 电压转换与离线处理

按商家确认的标称参数：Vref=2.42 V，PGA=6，24 位偏移二进制。
输入端电压 mV = (ecg_raw - 8388608) * 2420 / (6 * 8388608)。
这是标称电压换算，不是经过仪器校准的实测标定。

优先读取 ecg_raw，拒绝仅含单位不明 ecg_filtered 的文件。
时间戳如存在则检查与输入采样率一致；软件生成的连续时间戳不能证明无线链路无丢包。

从项目根目录运行：

```
python -m hardware.export_ads input.csv output_dir
```

输出 raw_mV.csv（单列未滤波 mV）、rhythm_filtered_mV.csv（单列离线节律显示滤波值）、metadata.json（来源哈希、参数及处理说明）。原文件不修改。
两份单列 CSV 可分别以 500 Hz 导入；滤波版不要再重复应用同样滤波。
默认模型 waveform 保持未滤波 mV；waveform_processed_mV 为单独对照。
滤波采用 SciPy：50 Hz Q=30 陷波、二阶 0.5–40 Hz Butterworth，双向零相位，仅适合离线节律研究。
双向滤波有边缘效应，不能用于实时逐点处理；不能据此测量诊断性 ST 幅值。
质量检查目前仅覆盖长度、有限值、平直和突变，不是临床质量通过证明。
没有自动输出心率、诊断或伪造模型结果。
