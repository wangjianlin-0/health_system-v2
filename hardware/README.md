# 硬件模块：硬件与采集集成

acquisition.py 提供统一回放样例和明确的未连接设备状态。firmware/src/main.c 为原固件草案，尚未实现采样。实际设备与输出接口必须核实后再定；不默认已具备USB或无线能力。

后续实现采样/缓存/传输、开始停止、序号丢帧、单位换算与适配器；输出标准信号供统一流水线处理，软件状态展示与两位软件负责人协作。回放可用于联调，不能当真实采集成果。

依据[根 README](../README.md)，真实协议见[待确认草案](../interfaces/hardware_protocol.md)。首版单导联；当前上传只接受单列 CSV，多列硬件 CSV 测试与解析实现的冲突尚待解决。
